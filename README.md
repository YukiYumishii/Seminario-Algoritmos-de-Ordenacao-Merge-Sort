## Sobre o Projeto
 Este projeto acadêmico foi desenvolvido pelos integrantes do Grupo 5 como requisito avaliativo da disciplina de Estrutura de Dados, ministrada pelo professor Karlson Tellicio Bezerra de Lima Guabiraba.

 O trabalho tem como objetivo apresentar e explorar o algoritmo de ordenação Merge Sort, abordando seus fundamentos, funcionamento, etapas de execução e aplicações práticas.

 A apresentação busca demonstrar, de forma didática e visual, como o algoritmo utiliza a estratégia de Divisão e Conquista para organizar elementos de maneira eficiente.

## Objetivos

- Compreender os fundamentos e o funcionamento do algoritmo Merge Sort.
- Demonstrar sua execução por meio de exemplos práticos e implementação em Python.
- Analisar sua eficiência, estabilidade e uso de memória.
- Explorar aplicações do algoritmo em diferentes contextos.
